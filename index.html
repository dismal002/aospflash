    devices

    Enable Developer Options

    To fully prepare your device and enable it to connect, update the following 3 settings. If your device is in the bootloader you can skip this process.

    BUILD ID 101112 touch_app

    Setting 1: Enable Developer Options Menu

    Tap the Build Number option 7 times to enable developer options.

    Android P+ (9.0+) - Settings > About Phone > Build Number

    Android O (8.0) - Settings > System > About Phone > Build Number

    Android N and before - Settings > About Phone > Build Number

    USB debugging

    Setting 2: Enable USB Debugging

    Toggle the USB debugging setting on within developer options menu.

    Android P+ (9.0+) - Settings > System > Advanced > Developer Options > USB debugging

    Android O (8.0) - Settings > System > Developer Options > USB debugging

    Android N and before - Settings > Developer Options > USB debugging

    OEM Unlocking

    Setting 3: Enable OEM Unlocking

    Toggle the OEM unlocking setting on in the developer options menu.

    Android P+ (9.0+) - Settings > System > Advanced > Developer Options > OEM unlocking

    Android O (8.0) - Settings > System > Developer Options > OEM unlocking

    Android N and before - Settings > Developer Options > OEM unlocking

    If the option is grayed out with "Bootloader is already unlocked" or is already toggled on, then skip this step. If you are unable to enable the option, ensure the device is connected to the internet or follow these instructions.
